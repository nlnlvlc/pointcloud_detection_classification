# Object Detection and Classification using Dense 3D Point Clouds

This project explores which methods of detection and/or classification are most suitable for general and niche uses. To that end, I've implemented feature-based, DBSCAN, random forest, and PointNet algorithms in an effort to evaluate their accuracy, execution time, and qualitative utility when processing dense 3D point clouds to perform detection and classification tasks.

## Need To Know

A core feature of this project is the `point cloud`, a representation of an image or object in a 3D space. Point clouds are a collection of points showing the location of one point relative to all the other points. These points can be generated by a number of methods. The method utilized in this project is *Li*ght *D*etection *A*nd *R*anging, also known as `LiDAR`.

`LiDAR` is a **time of flight** method which uses a series of lasers of other concentrated light sources to determine the distance of each point from the source by measuring how long it took any given point to reach surface. The faster the light source reaches a surface, the closer that point is to the source.

Collectively, `point clouds` and `LiDAR` can be utilized for various means, such as surveying environments, autonoumous navigation, and AR/VR boundaries & object detection, to name a few.


## Algorithm Solutions

There are three main algorithmic categories that can be used for detection, classification, or both. These algorithms are described as below.

| Algorithm Class | Description | Examples |
| --- | --- | -- |
| Geometric | Processes basic geometric features, all points relative to a single point | Feature-based and Convex Algorithms |
| Statistical | Determine probability that groups of points are a part of the same object | Density-Based Clustering (DBSCAN) and Random Forest Algorithms |
| Deep Learning | Processes raw point clouds to identify patterns | PointNet and PointNet++ Deep Learning Models |
| Hybrid | Combination of algorithms for greater performance | DBSCAN-PointNet Hybrid Algorithms |
